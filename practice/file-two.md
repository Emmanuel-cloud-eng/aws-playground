# File Two — Git Concepts

## The Three Stages of Git

1. Working Directory — where I make changes
2. Staging Area — where I prepare changes for a commit
3. Repository — the permanent history of commits

## Key Terms

- Commit: A saved snapshot of my project
- Branch: A separate timeline of commits
- Remote: The GitHub version of my repository
- Clone: A local copy of a GitHub repository

## The Four Core Commands

| Command | Stage | What it does |
|---------|-------|-------------|
| git status | Any | Shows current state of repository |
| git add | Working → Staging | Moves changes to staging area |
| git commit | Staging → Repository | Creates a permanent snapshot |
| git push | Repository → GitHub | Uploads commits to GitHub |
