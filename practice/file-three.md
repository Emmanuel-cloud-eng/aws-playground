# File Three — Commit Message Practice

## Rules for Good Commit Messages

1. Start with a verb: Add, Fix, Update, Remove, Create, Configure
2. Be specific about what changed
3. Keep the first line under 50 characters
4. Don't end with a period

## Examples

### Bad commit messages:
- "stuff"
- "fix"
- "updates"
- "working now"
- "aaaaaa"

### Good commit messages:
- "Add S3 bucket creation script"
- "Fix typo in IAM policy document"
- "Update README with VPC section"
- "Remove unused EC2 configuration file"
- "Configure billing alarm at five dollar threshold"
