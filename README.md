# AWS Playground 🚀

My personal hands-on learning environment for AWS, Git, and DevOps.

## Purpose

This repository is my structured workspace for learning AWS cloud services.
I use it to practice, document, and track my progress as I build cloud
engineering skills.

## Repository Structure

aws-playground/
├── README.md # This file
├── .gitignore # Files and folders Git should ignore
├── docs/ # Learning notes and documentation
├── aws-cli/ # AWS CLI practice and scripts
├── iam/ # IAM (Identity & Access Management) practice
├── s3/ # S3 (Simple Storage Service) practice
└── scripts/ # Utility scripts and helpers


## Getting Started

1. Clone this repository: `git clone <repository-url>`
2. Configure AWS CLI: `aws configure`
3. Start with the exercises in `docs/`

## Security

⚠️ **No AWS credentials, access keys, or secrets are stored in this
repository.** All sensitive configuration is handled through environment
variables and AWS CLI profiles.
